# Доступ до npm registry

Якщо під час `npm install` отримуєте помилку `403 Forbidden`, скористайтесь наведеними нижче кроками для відновлення доступу до npm registry.

## 1. Перевірте коректність акаунта npm
- Увійдіть в обліковий запис: `npm login`.
- Переконайтеся, що використовується корпоративний обліковий запис (якщо доступ обмежено компанією).
- За потреби оновіть токен доступу: `npm token create --read-only` та додайте його у файл `~/.npmrc`.

## 2. Задайте явне registry
Якщо використовуєте внутрішній mirror або приватний proxy, пропишіть його у `.npmrc`:

```ini
registry=https://registry.npmjs.org/
# або корпоративне дзеркало
# registry=https://<ваш-mirror>/
```

Після цього повторіть `npm install`.

## 3. Налаштуйте проксі (за потреби)
У середовищах з обов'язковим HTTP/HTTPS-проксі виконайте:

```bash
npm config set proxy http://user:pass@proxy.company.com:8080
npm config set https-proxy http://user:pass@proxy.company.com:8080
```

Перевірте, що проксі дозволяє запити до `registry.npmjs.org`.

## 4. Дозвольте брандмауерні з'єднання
- Відкрийте порти 80/443 до `registry.npmjs.org` та `registry.npmjs.com` у брандмауері.
- Додайте їх у список дозволених, якщо використовується корпоративний VPN або мережевий фаєрвол.

## 5. Перевірте npm cache
Інколи допомагає очищення локального кешу:

```bash
npm cache clean --force
```

## 6. Використовуйте офлайн-пакети (альтернатива)
Якщо онлайн-доступ неможливий:

1. Завантажте `.tgz` пакунки з інтернету з іншого середовища.
2. Розмістіть їх у локальному сховищі.
3. Встановіть командою `npm install ./path/to/package.tgz`.

Ці дії забезпечують встановлення залежностей навіть у середовищах з обмеженим доступом до публічних registry.
